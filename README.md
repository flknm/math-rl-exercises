# Mathematics of Reinforcement Learning

**Interactive Exercises | Heinrich Heine University Düsseldorf**

Welcome to the interactive exercises accompanying the course *Mathematics of Reinforcement Learning*.

[**Open JupyterLite and start working**](https://flknm.github.io/math-rl-exercises/)

## What you'll find here

Use the Jupyter notebooks to explore ideas from the course through Python implementations, numerical experiments, simulations, and visualizations. Some notebooks complement the programming tasks on the problem sheets; others give you additional opportunities to experiment with mathematical concepts.

## Working with the notebooks

You can open, edit, and run the notebooks directly in your browser. **You don't need to install Python or Jupyter.**

Your edits are stored locally in your browser, **not in this GitHub repository**. Download your completed notebooks to keep a backup, especially before clearing browser data or switching devices.

## Course materials and submissions

For the official problem sheets, deadlines, announcements, and submission folders, please use **ILIAS**.

If an exercise requires you to submit a solution, submit it **via ILIAS**, following the instructions on the corresponding problem sheet. Working in JupyterLite does not submit your work automatically.
